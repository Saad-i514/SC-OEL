# Stockroom artwork

Created with the built-in image-generation tool for this project. Both PNGs are bundled locally; the application does not fetch images at runtime.

## warehouse.png

Final prompt:

> Use case: stylized-concept. Create a premium 3D editorial illustration for an inventory management desktop application called Stockroom. Landscape 1536x1024. A beautifully detailed isometric miniature warehouse: cream shelving with neatly arranged small cardboard boxes, a teal hand trolley, one large parcel in front, restrained orange accents, a small leafy plant. Soft sculpted clay materials, sophisticated ambient occlusion, studio lighting, minimal elevated product-design aesthetic. Entire background solid very pale mint #e7f4ef. Composition centered with ample breathing room and no cropped objects. No people, no text, no lettering, no numbers, no logos, no watermark. Intended as an actual hero art asset, not a UI screenshot.

## activity.png

Final prompt:

> Use case: stylized-concept. Asset type: illustration for activity page of premium inventory desktop app. Landscape 1536x1024. Beautiful minimal 3D clay still life: a cream clipboard with a few simple teal check marks (no words), a small closed cardboard parcel, a teal pen resting beside the clipboard, and a small warm orange desk clock. Soft studio lighting, refined ambient shadows, clean sculpted forms, muted cream and teal palette with restrained orange details. Solid pale mint background #e7f4ef, centered objects with generous margins. No people, no logos, no watermark, no text or letters. Actual art asset, not a UI screenshot.
